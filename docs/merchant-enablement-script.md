# Merchant Enablement Script — AI Ad Agent Call/WhatsApp

> Use this script when calling or WhatsApp-messaging a shopkeeper to explain how the AI ad agent will set up their Facebook/Instagram campaign. Written in easy Hindi-English mix (Hinglish) for real conversations.

---

## Opening (30 seconds)

"Hi [Merchant Name], yeh [Your Company] ka call hai. Aapka shop ka name sunke bahut khushi hui. Aaj aapko batata hoon ki humari AI ad agent automatically ek Facebook aur Instagram ad campaign banayegi aapke liye — bilkul free mein."

## What the AI Does (45 seconds)

- "Pehle AI aapke shop ki location, category, aur products padh leti hai."
- "Phir target audience decide karti hai — jaise 5 km ke andar 25–45 saal ke log jo fresh products ko search karte hain."
- "Ad creative bhi banati hai — photo + text + CTA button ('Shop Now' ya 'Call Now')."
- "Campaign ek click mein live ho jaati hai — aapko kuch download karne nahi."

## What the Merchant Needs to Approve (30 seconds)

1. **Business name & photo** — "Kya aap ki photo use karne do ya shop ka interior?"
2. **Ad text** — "Ye line approve karein: '[Your Shop] mein fresh [product] milein — today free delivery!'"
3. **Daily budget** — "Kitna spend karna hai? ₹100 / ₹200 / ₹500?"
4. **Go-live date** — "Aaj, kal, ya specific din?"

## Common Merchant Questions

### "Why is my ad not live yet?"

"Bhai, ad approval mein hota hai 15–30 minutes. Facebook pehle scan karta hai — koi prohibited content nahi toh auto-approve ho jaata hai. Agar late lag raha hai toh main check karungi."

### "Why was my ad rejected?"

"Do common reasons hote hain:
- Photo mein text zyada tha (Facebook rule: <20% text on image)
- Before/after claim ya 'guaranteed result' type wording

Fix karke dobara submit karunga — same din live."

### "Kya main return le sakta hoon?"

"Haan, campaign paise ka hisaab monthly hota hai. Agar ₹500 spend hua aur result nahi dekha toh pause kar do — balance wapst aa jaayega."

## Closing (15 seconds)

"Simple na? Main aapke WhatsApp pe approval request bhejungi — ek click aur campaign live. Aaj ka din ka time kaise aata hai?"

---

## Quick Checklist for the Call

- [ ] Merchant name, shop category, location noted
- [ ] Approved ad creative screenshot share ki
- [ ] Daily budget + start date confirmed
- [ ] Follow-up date set (usually 3 days later)
- [ ] Escalation logged if merchant confused / angry
